# 通用发行边界复审（2026-09-18）

## 范围

对可提交的源码、配置样例、文档、脚本与 CI 配置运行非敏感静态审计，排除 `target/`、
`artifacts/`、`vendor/` 和 .NET 构建目录。目标是避免部署者的网络与密钥信息误入通用发行版。

## 结果

- 24 位十六进制密钥形态扫描：0 个命中。
- 初始 IPv4 形态扫描命中两个文件：桌面应用清单和 NuGet 锁文件。逐项审阅后确认它们只含
  程序/依赖版本号（例如 `1.0.0.0` 和 `7.3.0.3`），不是网络地址。
- 源码中保留的网络示例仅为环回、`*.example` 或 `*.invalid` 端点；它们不绑定任何部署者。
- 当前 Windows/Linux 发行载荷只含程序、锁定上游资产、许可证、SBOM、通用文档和样例，不含
  Server 环境文件、客户端 DPAPI 文件或运行状态。

## 结论与限制

审计没有发现部署者网络或密钥进入可提交内容和当前发行物。静态形态扫描不能替代发布前的人工
审阅，也不能证明未来修改自动安全；任何新增配置字段、诊断字段或包载荷都必须重跑该审计。
