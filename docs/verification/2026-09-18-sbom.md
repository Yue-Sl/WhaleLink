# 锁定依赖 SPDX SBOM（2026-09-18）

## 结果

- `scripts/generate-sbom.ps1` 使用 `cargo metadata --locked --offline`、Desktop
  `packages.lock.json` 与 EasyTier v2.6.4 锁定信息生成 SPDX 2.3 JSON。
- Windows 便携发行载荷中的 `SBOM.spdx.json` 包含 155 个组件。
- 结构检查通过：`spdxVersion=SPDX-2.3`，EasyTier `2.6.4` 组件存在。
- 同一发行目录 `SHA256SUMS.txt` 的 98 个条目均复算一致。

## 边界

SBOM 只反映锁定依赖元数据，不含用户配置、令牌、邀请码、网络密钥或服务器信息。对无法从
现有锁文件确定的第三方许可证使用 SPDX `NOASSERTION`；正式发布前仍必须逐项完成许可证审查
并随发行物附带适用的上游许可证文本。
