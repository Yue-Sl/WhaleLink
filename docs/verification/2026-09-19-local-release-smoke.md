# 2026-09-19 本机发行包试运行

## 通过项目

- 验证 Windows 便携发行目录包含守护进程、EasyTier Core/CLI、连接脚本和使用说明。
- 使用随机网络名、随机密钥和本机回环 Relay 启动一个独立 EasyTier 节点，再由发行包内
  `whalelinkd connect --no-tun` 启动第二个节点；其本机 RPC 成功返回对端状态。
- 发现强制结束守护进程会让 EasyTier 子进程遗留。已通过 Windows Job Object 的
  `KILL_ON_JOB_CLOSE` 修复，并以随机隔离节点验证：守护进程被强制结束后，子进程自动结束。
- 测试前后均检查并清理本次创建的节点；现网服务和部署者已有独立测试节点未被停止或重启。

## 未作为产品失败处理的结果

- 非提升会话无法创建 Windows TUN，属于 Windows 管理员权限要求，发行连接脚本已显式要求提升权限。
- 提升环境中的“同机双 TUN、同子网 ICMP”测试未收到 ICMP 回包。这种布局会受到本机多适配器
  路由和防火墙选择影响，不能据此判断远端联机功能失败。
- 自动化会话对 UAC 提升进程未稳定回传结果文件，故未声称真实远端 TUN 验收通过。正确后续验收
  是由管理员在交互式桌面使用发行包连接已在线的独立服务器对端，并验证目标业务端口。

## 安全边界

本次随机测试未使用、写入或记录部署者的 Relay、网络名、密钥、虚拟地址、令牌或邀请码。
