# ADR 0004：恢复工作区 `.git` 的所有权与 ACL

- **状态：** Accepted
- **日期：** 2026-09-17

## 事件

对既有文件执行 `apply_patch` 时，沙箱在读取前持续返回 `windows sandbox helper: setup refresh had errors`；
新增文件不受影响。

## 根因与修复

`.git` 的所有者曾是受限服务身份，且 ACL 不能让工作区沙箱写入其保护规则。用户已将
所有者还原为交互工作区所有者，并重置为正常继承；之后对 `Cargo.toml` 的真实依赖编辑成功。

## 决策

保留先前阻塞记录以便审计。后续遇到只影响更新既有文件、而新增文件正常的沙箱错误时，先检查
`.git` 所有权与 ACL；不得绕过 `apply_patch` 写入源码。
