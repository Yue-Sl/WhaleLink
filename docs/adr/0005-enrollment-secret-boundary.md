# ADR 0005：入网密钥不进入 TOML 或控制面快照

- **状态：** 已接受
- **日期：** 2026-09-18

## 背景

邀请码兑换必须向客户端交付真实 EasyTier 入网材料，但房间 `network_secret` 不能被提交到
仓库、写入普通 TOML、日志、诊断包或 Server 状态快照。

## 决策

固定房间 TOML 只保存 `network_name`、Relay/seed `peers` 和 `network_secret_env` 变量名。
Server 启动时从受限服务环境读取密钥并校验最小长度；兑换 API 返回结构化的
`DataPlaneEnrollment`。客户端负责将该响应以 DPAPI 保存。持久化快照跳过入网材料，服务
重启时严格以同一房间配置重新注入；房间 ID 或显示名漂移时拒绝加载旧快照。

## 后果

- Server 环境变量和进程环境成为敏感配置，部署时必须由系统权限保护。
- 控制面状态文件可安全备份到受限存储，但仍包含成员与邀请码摘要，不能公开。
- 管理员轮换密钥后须同步更新受限环境并轮换凭据；自动化密钥轮换留待有真实 Relay 部署时完成。
